1. VISÃO GERAL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Este projeto é um sistema web para controle financeiro e cálculo de
preços de vendas de brownies. Ele é dividido em duas camadas:

  BACKEND  →  Python (Flask)    — calcula e armazena dados em memória
  FRONTEND →  HTML + CSS + JS   — interface que o usuário vê no browser

As duas camadas se comunicam por uma API REST: o frontend faz
requisições HTTP (fetch) para o backend, que responde em JSON.

─── backend/logica_calculos.py ───────────────────────────────────────

  Contém as funções matemáticas do projeto. É o "coração" das regras
  de negócio. Não tem nenhuma lógica de servidor ou interface — só
  recebe valores numéricos, calcula e retorna resultados.

  Funções:

  calcular_lucro_unidade(custo, preco_venda)
    → Retorna: preco_venda - custo
    → Uso: descobrir quanto se ganha por brownie vendido.

  calcular_percentual_lucro(custo, preco_venda)
    → Retorna: (lucro / custo) × 100
    → Uso: saber a margem percentual sobre o custo.

  calcular_vendas_totais(custo, preco_venda, quantidade)
    → Retorna: dicionário com receita_total, custo_total,
               lucro_total, percentual_lucro
    → Uso: simular o resultado de vender um lote completo.

  calcular_preco_venda_markup(custo, markup_percent)
    → Retorna: custo × (1 + markup/100)
    → Uso: definir o preço de venda a partir de uma margem desejada.

  menu_calculadora()
    → Interface de texto (CLI) para testar as funções diretamente
      no terminal, sem precisar do navegador.

─── backend/main.py ──────────────────────────────────────────────────

  Servidor web construído com Flask. Faz três coisas:

  1. SERVE OS ARQUIVOS HTML
     GET /             → envia web/index.html
     GET /calculadora  → envia web/calculadora.html

  2. EXPÕE OS CÁLCULOS COMO ENDPOINTS HTTP
     POST /api/lucro-unidade    → chama calcular_lucro_unidade()
     POST /api/percentual-lucro → chama calcular_percentual_lucro()
     POST /api/vendas-totais    → chama calcular_vendas_totais()
     POST /api/markup           → chama calcular_preco_venda_markup()

  3. GERENCIA O ESTADO DE VENDAS/GASTOS
     POST /api/venda   → registra uma venda na lista em memória
     POST /api/gasto   → registra um gasto na lista em memória
     GET  /api/resumo  → retorna totais e histórico completo
     POST /api/resetar → limpa todos os registros

  O CORS está habilitado para que o browser possa chamar a API
  mesmo quando o HTML é aberto diretamente como arquivo local.

─── web/index.html ───────────────────────────────────────────────────

  Página principal. Exibe quatro cards:
  - "Adicionar Venda":  campo numérico + botão que chama adicionarVenda()
  - "Adicionar Gasto":  campo numérico + botão que chama adicionarGasto()
  - "Resumo":           mostra total de vendas, gastos e lucro
  - "Histórico":        lista todas as entradas registradas
  - Link "→ Abrir Calculadora de Preços" que navega para /calculadora

  Carrega: css/codigo.css e js/codigo.js

─── web/calculadora.html ─────────────────────────────────────────────

  Nova interface minimalista com quatro cards, um para cada cálculo
  do backend:

  Card 01 — Lucro por Unidade      (usa /api/lucro-unidade)
  Card 02 — Percentual de Lucro    (usa /api/percentual-lucro)
  Card 03 — Totais de Vendas       (usa /api/vendas-totais)
  Card 04 — Preço por Markup       (usa /api/markup)

  Também exibe uma barra de status que indica se o servidor Flask
  está online ou offline.

  Carrega: css/calculadora.css e js/calculadora.js

─── web/css/codigo.css ───────────────────────────────────────────────

  Estilos da página principal (index.html). Tema marrom/chocolate
  que combina com a temática de brownies. Define cards, botões,
  inputs e o card de resumo com fundo laranja claro.

─── web/css/calculadora.css ──────────────────────────────────────────

  Estilos da calculadora. Design minimalista:
  - Paleta em tons de cinza claro (#F7F7F5, #FFFFFF, #E2E2DE)
  - Tipografia: IBM Plex Sans (texto) + IBM Plex Mono (números)
  - Sem bordas arredondadas excessivas, sem sombras pesadas
  - Resultados coloridos: azul (neutro), verde (positivo), vermelho (negativo)
  - Layout em grid 2 colunas que colapsa para 1 no celular

─── web/css/global.css ───────────────────────────────────────────────

  Arquivo base importado pelo codigo.css. Reservado para variáveis
  CSS e resets compartilhados entre páginas futuras.

─── web/js/codigo.js ─────────────────────────────────────────────────

  Lógica JavaScript do index.html. Ao carregar, tenta conectar ao
  servidor (checarAPI). Se conseguir, sincroniza os dados salvos
  no servidor (sincronizarResumo). Se não conseguir, opera em modo
  local (só memória do browser, dados somem ao recarregar).

  Funções principais:
  - checarAPI()        → testa GET /api/resumo para saber se API está ativa
  - sincronizarResumo() → atualiza tela com dados do servidor
  - adicionarVenda()   → POST /api/venda → fallback local se offline
  - adicionarGasto()   → POST /api/gasto → fallback local se offline
  - resetar()          → POST /api/resetar + limpa estado local
  - atualizarResumo()  → atualiza os três parágrafos do card Resumo
  - atualizarHistorico() → renderiza a lista de entradas

─── web/js/calculadora.js ────────────────────────────────────────────

  Lógica JavaScript da calculadora. Cada função de cálculo:
    1. Lê os inputs da tela
    2. Valida os valores
    3. Faz fetch POST para o endpoint correspondente no backend
    4. Exibe o resultado na área abaixo dos inputs
    5. Se o servidor estiver offline, exibe mensagem de erro clara

  Funções:
  - verificarServidor() → atualiza o indicador de status no topo
  - calcLucroUnidade()  → POST /api/lucro-unidade
  - calcPercentual()    → POST /api/percentual-lucro
  - calcTotais()        → POST /api/vendas-totais
  - calcMarkup()        → POST /api/markup

  Suporte a tecla Enter: pressionar Enter em qualquer input
  executa o cálculo do card correspondente.

5. COMO EXECUTAR O SITE (PASSO A PASSO)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PRÉ-REQUISITOS
──────────────
  - Python 3.8 ou superior instalado
  - pip (gerenciador de pacotes do Python)
  - Conexão com internet (apenas para carregar as fontes do Google Fonts)

PASSO 1 — Instalar as dependências Python
────────────────────────────────────────────
  Abra o terminal na pasta raiz do projeto (onde está a pasta "backend")
  e execute:

    pip install flask flask-cors

  Isso instala:
    flask       → framework web para criar o servidor e a API
    flask-cors  → permite que o browser acesse a API sem erros de CORS

PASSO 2 — Iniciar o servidor
──────────────────────────────
  No terminal, navegue até a pasta backend:

    cd tcc/backend

  Em seguida, execute:

    python main.py

  Você verá a mensagem:
    Servidor: http://localhost:5000
    * Running on http://127.0.0.1:5000

  IMPORTANTE: mantenha este terminal aberto enquanto usar o site.
  Se fechar o terminal, o servidor para e a API fica offline.

PASSO 3 — Abrir o site no browser
────────────────────────────────────
  Com o servidor rodando, abra qualquer navegador e acesse:

    http://localhost:5000          → página de controle de vendas
    http://localhost:5000/calculadora  → calculadora de preços

  NÃO abra os arquivos .html diretamente pelo explorador de arquivos
  (file://...) se quiser que os dados persistam entre sessões. Abrir
  via file:// ainda funciona para visualizar a interface, mas o
  estado de vendas/gastos não será salvo no servidor.

PASSO 4 — Usar a aplicação
────────────────────────────
  Página principal (http://localhost:5000):
  - Digite um valor nos campos e clique nos botões (ou pressione Enter)
  - O resumo é atualizado em tempo real
  - O histórico mostra cada entrada individualmente
  - "Limpar tudo" apaga todos os registros do servidor

  Calculadora (http://localhost:5000/calculadora):
  - A barra de status no topo mostra se o servidor está conectado
  - Preencha os campos do card desejado e clique em "Calcular"
  - O resultado aparece abaixo dos inputs com cor indicativa
    (verde = positivo, vermelho = negativo)
  - Pressionar Enter em qualquer campo também executa o cálculo

6. OBSERVAÇÕES IMPORTANTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  - Os dados de vendas e gastos são armazenados na memória do servidor
    (listas Python dentro de main.py). Isso significa que ao reiniciar
    o servidor, os dados são perdidos. Para um projeto futuro, os dados
    poderiam ser salvos em um banco de dados (SQLite, por exemplo).

  - A calculadora (calculadora.html) não armazena nada — cada cálculo
    é realizado sob demanda e o resultado é mostrado na tela.

  - O site funciona parcialmente sem o servidor: a interface carrega e
    os inputs funcionam, mas os cálculos da calculadora retornam erro e
    o controle de vendas opera apenas em memória local (perde dados ao
    recarregar).

  - Para testar as funções de cálculo sem abrir o browser, execute:
      python backend/logica_calculos.py
    Isso abre o menu interativo de texto (CLI).
